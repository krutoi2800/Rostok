Росток для krutoi2800.github.io/Rostok/

1. В существующем репозитории Rostok обнови файлы из архива. Файл index.html должен остаться в корне, адрес сайта — прежним. Старые планы читаются из того же ключа rostok.planner.v1. У каждого посетителя данные лежат в его браузере. В разделе «Профиль → Резервная копия» можно скачать личный файл и восстановиться из него на другом телефоне. Копия содержит ключ дружбы владельца, поэтому её не стоит отправлять друзьям. Им передавай только ID.

2. Фото желания прикрепляется в разделе «Вишлист» при создании или редактировании. Фото сохраняется с текстом на устройстве. Статическая часть работает на GitHub Pages сама по себе.

3. Для друзей нужен один общий HTTPS-сервер. Ниже два варианта. Если в config.js уже указан работающий сервер, этот шаг можно пропустить.

Cloudflare Workers + D1
• Из папки backend запусти npx wrangler login, затем npx wrangler d1 create rostok-friends.
• Скопируй полученный database_id в backend/wrangler.jsonc вместо PASTE_DATABASE_ID.
• Выполни npx wrangler d1 execute rostok-friends --remote --file=schema.sql, затем npx wrangler deploy.
• Скопируй HTTPS-адрес Worker в config.js между кавычками. Загрузи обновлённый config.js в свой репозиторий. Путь /friends добавляется автоматически.

Сервер с Node.js и постоянным диском
• На хостинге с Node.js 22.13 или новее положи файлы из backend в одну папку и запусти node server.mjs. Зависимости устанавливать не нужно.
• Порт задаётся переменной PORT (по умолчанию 8787). Переменной ROSTOK_DATABASE задай путь к файлу SQLite на постоянном диске. При обновлении сервера сохраняй базу.
• Подключи HTTPS-домен хостинга, затем укажи его в config.js и обнови этот файл в GitHub. На хостинге с временным диском выбери другой вариант.

4. Оба человека открывают один и тот же сайт. При первом открытии зарегистрируется ID этого браузера. В профиле один копирует ID, другой вставляет его в «ID друга». Получатель принимает входящую заявку. Кнопка «Обновить» показывает её сразу. Пока открыт профиль, список обновляется также каждые 30 секунд. Дружба не публикует личные планы и фотографии.

Если сайт размещён под другим аккаунтом GitHub, замени allowedOrigin в backend/worker.mjs на свой origin перед публикацией сервера.
